目前的映射:

拨轮向下打到底进入紧急停止模式(后续改为关闭遥控器停止,利用daemon; daemon已经模块完成);拨轮向上打开启摩擦轮,超过一半开始发射(速度环,连发)

左侧开关:
- 上:键鼠控制
- 中:视觉控制(没有识别到目标的时候仍然可以使用遥控器控制云台)
- 下:遥控器控制

右侧开关:
- 上:弹舱开
- 中:底盘云台分离(底盘不旋转,全向移动)
- 下:底盘跟随云台

## 两种接收机都支持(自动识别,不用重新编译)

车上可以插两种接收机,插哪个用哪个:

| | DBUS(原来那套) | SBUS(新遥控器 ET08A) |
| --- | --- | --- |
| 发射机 / 接收机 | 大疆 DT7 + DR16 | ET08A + RF206S(最后一个端口设成 W.BUS) |
| 一帧长度 | 18 字节 | 25 字节(0x0F 开头、0x00 结尾,里面 16 个 11 位通道) |
| 鼠标 / 键盘 | 有(图传链路注进来的) | 没有 |

两者在电气上是一样的(100000 波特、偶校验、**反相**),所以接同一根线(C 板遥控口 = USART3 的 PC11),
硬件不用改。模块层按"连续 3 帧都像 SBUS 才切过去"自动识别,偶发干扰不会误判。

### ET08A(RF206S)的用法
1. 发射机长按电源键开机;【通信设置】→【对码】。接收机通电后长按 SET 3 秒,橙灯慢闪,等发射机发对码指令。
2. 【通信设置】→【接收机端口设置】把**最后一个端口**切成 **W.BUS**,返回上级保存。LED 绿色常亮 = W.BUS 正常
   (紫=PWM,蓝=PPM,红=无信号,红慢闪=低电压)。
3. 接收机供电 3.8~6.5V(接 C 板 5V,不要接电池主电),两根天线摆成 90°、伸出车体的金属/碳纤之外。
4. 信号线接原来 DR16 那根(信号 ↔ PC11),正负别接反,共地。

### ET08A 的默认通道(重要)

ET08A 说明书里的【固定翼 + 摇杆模式1】默认连接是:

| 通道 | 发射机默认功能 | 控制件 | 本项目用途 |
| --- | --- | --- | --- |
| CH1 | 副翼 | J1(右摇杆水平) | **底盘转弯**(右摇杆水平) |
| CH2 | 升降舵 | J3(右摇杆竖直) | 底盘前后 |
| CH3 | 油门 | **LD 旋钮** | **云台匀速目标**,映射到 0~20rad/s |
| CH4 | 方向舵 | **RD 旋钮** | **底盘速度**,映射到 0~1.0m/s |
| CH5 | 起落架 | **SD(右两档)** | **A 拨杆**(本车实测在 CH5) |
| CH6 | 辅助1 | 默认未分配 | **D 拨杆**(本车实测在 CH6) |
| CH7 | 辅助2 | 默认未分配 | **C 拨杆**,需要手动分配给 SC |
| CH8 | 辅助3 | 默认未分配 | 未使用 |

本车实测和说明书的出厂分配不同:A 实际在 CH5、D 实际在 CH6,而且两路都是
**上=低值、下=高值**。代码里因此写成 `A=CH5、D=CH6、C=CH7`,并把 A/D 两路都反向。
这不是"按说明书猜的",是以当前实机行为为准;如果以后重新分配通道,以
`rc_dbg_sw_left_raw` / `rc_dbg_sw_right_raw` 为准改回对应宏。

在 ET08A 上做一次通道分配:

1. 【通用功能】→【通道设置】,把 CH3 的控制件设为 **LD**,CH4 设为 **RD**;
2. 把 CH5 的控制件设为 **SA**,CH6 设为 **SD**,CH7 的功能设为"辅助2"并选 **SC**;
3. 保存后回到【通用功能】→【监视器】,逐个转 LD/RD、拨 SA/SD/SC,确认 CH3/CH4/CH5/CH6/CH7 跟着动;
4. 本车代码当前按 **上=低值(约352),下=高值(约1696)** 处理 A/D;
   C 实测也是"下=高、上=低",代码里 `RC_SBUS_INVERT_DIAL=1` 已把它翻回来,
   所以逻辑上下=停、中=摇杆、上=来回。若你在发射机里把 A/D 正反设置改成了
   "上=高、下=低",请把 `RC_SBUS_INVERT_SW_LEFT/RIGHT` 改回 0。

LD/CH3、RD/CH4 使用旋钮的完整行程作线性映射:

- LD: 352~1696 -> 云台匀速目标 `0~20rad/s`(约 `0~1145.9°/s`)
- RD: 352~1696 -> 底盘目标 `0~1.0m/s`

云台变速档把 LD 的 `0~660` 全行程直接映射为 `0~10rad/s²` 正向加速度。
LD 最低端为0加速度,此时保持当前目标速度;LD 最大端执行最快的
`0→+7→0→+7rad/s` 正向三角波。

Ozone watch 里看 `rc_dbg_ld_raw` / `rc_dbg_rd_raw` 核对两端原始值,看
`rc_dbg_ld_percent` / `rc_dbg_rd_percent` 核对百分比,看
`gimbal_ld_target_speed` / `chassis_rd_target_speed` 核对最终目标值。
旋钮方向反了就把 `RC_SBUS_INVERT_LD` 或 `RC_SBUS_INVERT_RD` 改成 1。

如果不想改发射机,也可以把 `RC_SBUS_CH_*` 改成你实际使用的通道;
但**不要只按"CH5/CH6/CH7"猜**,必须用下面的原始值确认。

### 通道映射怎么核对 / 怎么改

`RC_SBUS_CH_*`(在 `remote_control.h`)决定"哪路功能取第几个通道"。
拿到遥控器后打开 Ozone 的 watch 窗口加 `rc_dbg_ch[0..15]`,一次只动一个摇杆/开关,
看哪个下标跟着变 —— 那个下标就是它占的通道,填回 `RC_SBUS_CH_*` 即可(0 = 第 1 通道)。
三个开关的原始值也可以直接看 `rc_dbg_sw_left_raw`(A/CH5)、
`rc_dbg_sw_right_raw`(D/CH6)、`rc_dbg_dial_raw`(C/CH7)。

- 开关方向反了:优先去发射机【通用功能】→【正反设置】反转该通道;
  也可以在 `remote_control.h` 里改 `RC_SBUS_INVERT_SW_LEFT/RIGHT`
  (当前实机为两路都反向,所以是 1)。
- 三档开关"上/下"和期望相反:同上,反转该通道即可;判定阈值是 `RC_SBUS_SW_TH_LOW/HIGH`。
- A/D 是两档开关:通道落在中位时 `rc_dbg_sw_left/right` 会显示 **0(无效)**,
  固件会直接急停。看到 0 先检查 CH5/CH6 是否分配正确、开关是否真的在两档之一。
- 通道号若填得超出范围,编译会直接报错(`#error`),不会悄悄跑歪。

### 调试镜像(Ozone 的 watch 窗口里直接敲名字)

| 变量 | 含义 |
| --- | --- |
| `rc_dbg_protocol` | 认到的协议:0=还没认出来 1=DBUS 2=SBUS |
| `rc_dbg_ch[0..15]` | SBUS 每通道原始值(0~2047) |
| `rc_dbg_dbus_frames` / `rc_dbg_sbus_frames` | 各收到多少帧(数字不动就是没收到数据) |
| `rc_dbg_bad_frames` | SBUS 模式下丢掉的异常帧(半包/干扰);稳定工作时应该基本不变 |
| `rc_dbg_sw_left_raw` / `rc_dbg_sw_right_raw` / `rc_dbg_dial_raw` | A/D/C 三个开关所在通道的原始值 |
| `rc_dbg_sbus_flags` | SBUS 第24字节;bit2=丢帧、bit3=失控保护,任一置位时固件按离线急停 |

### 第一次上机的建议顺序
1. 车架空 / 电机断电,只看 `rc_dbg_protocol` 和帧计数有没有在涨。
2. 涨了再核对映射(见上),把 `RC_SBUS_CH_*` 填对。
3. 最后才给电机上电。
